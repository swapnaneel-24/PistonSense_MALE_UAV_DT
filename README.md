# PistonSense — Edge-to-Cloud Digital Twin

Observational piston-engine health-monitoring research prototype. Not certified or intended for aircraft control.

## Development

The approved master framework v1.1 governs architecture; its repository transfer is pending. The [historical framework](docs/Digital_Twin_Aero_Piston_Engine_MALE_UAV.md) and [provenance](docs/provenance_log.md) remain available.

Three workstreams: data research, core infrastructure, knowledge engineering. See [development plan](docs/implementation/phase-0.md).

Development fixtures are not scientific evidence. No real-engine diagnostic accuracy or RUL performance is claimed.
